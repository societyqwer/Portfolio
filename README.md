### 🟢 Особенности проекта

* 🖥️ **Terminal CLI Visuals:** Дизайн с моноширинными шрифтами, темной темой (`#0a0d14`) и изумрудными (`#10b981`) акцентами.
* 💻 **Интерактивная консоль:** Встроенный веб-терминал с поддержкой команд (`help`, `whoami`, `stack`, `projects`, `contact`, `clear`).
* 📱 **Адаптивная верстка:** Корректный отклик на мобильных устройствах, планшетах и десктопах (Tailwind CSS).
* ⚡ **Zero-Build Deployment:** Чистый стек без тяжелых сборщиков для моментальной загрузки через GitHub Pages.
